# Sonora v0.1.0

The first release of Sonora: self-hosted music analytics and personal listening recaps, delivered as a Docker Compose stack. The application UI is currently in German; the repository overview, quick start and deployment guide are now available in English.

## Included

- Last.fm and ListenBrainz connectors with configurable background synchronization and visible source status.
- CSV, JSON, official ListenBrainz export and personal Spotify export imports with validation, preview and background processing.
- Daily, weekly, monthly, yearly and custom-period analytics with local calendar boundaries and daylight-saving support.
- Top songs, artists and albums; activity charts; period comparisons; first appearances in the complete stored history.
- Separate measured and estimated listening time, explicit missing values and persistent data-gap warnings.
- Responsive dark/light dashboard, searchable listening history and locally exported PNG recap cards.
- Protected personal setup, encrypted source secrets, personal JSON export and data deletion.
- PostgreSQL persistence, migrations, healthchecks, a separate worker and an isolated read-only demo mode.

## Run with Docker

Get the versioned source:

```sh
git clone --branch v0.1.0 --depth 1 https://github.com/Lua-x/Sonora.git
cd Sonora
```

Generate `.env` with Node.js 24:

```sh
node scripts/setup-env.mjs
```

Or generate it with Docker in Bash or PowerShell:

```sh
docker run --rm -v "${PWD}:/app" -w /app public.ecr.aws/docker/library/node:24.21.0-bookworm-slim node scripts/setup-env.mjs
```

Set `SONORA_IMAGE=ghcr.io/lua-x/sonora:0.1.0` in `.env`, then:

```sh
docker compose pull web worker migrate
docker compose up -d --no-build
```

The published image supports **Linux/amd64**. A source build is also available with `docker compose up -d --build`. If GHCR requires authentication, use an authorized account with `read:packages` access.

Open `http://localhost:3000` on the Docker host and complete setup with the token in `.env`. For a server or NAS accessed from other devices, configure the reverse proxy and `APP_URL` as described in the [English deployment guide](https://github.com/Lua-x/Sonora/blob/v0.1.0/docs/deployment.md).

## Verification

- 80 automated tests, typecheck, lint and production build passed for the application baseline.
- Release CI checks the versioned source again before publication, including the production dependency audit.
- Docker integration checks cover setup, protected access, worker imports, deduplication, all four recap periods, JSON export and persistence after container recreation.
- Setup, import, history, responsive navigation, recaps and an actual PNG download were checked in a browser.

## Known scope and limitations

- Live synchronization against the owner's Last.fm or ListenBrainz account has not been verified. Accounts will be connected after installation; connector tests use controlled responses.
- The user interface is German. Other CPU architectures have not been verified.
- There is no direct Spotify API integration. Only personal export files are supported, with the documented usage scope.
- Cross-source overlaps are flagged rather than silently merged. Missing provider history cannot be reconstructed automatically.
- This is the initial release. There is no migration from an earlier Sonora release. Keep a database backup and the matching `.env` before future updates.
