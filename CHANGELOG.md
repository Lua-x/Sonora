# Changelog

## 0.1.0 — 2026-10-11

Initial release of the Docker-based personal music analytics app. Includes Last.fm and ListenBrainz connectors, personal file imports, calendar-aware analytics, responsive dashboard, listening history, recap cards, protected setup and data export/deletion.

The release includes import identity-conflict detection, persistent gap warnings and discovery calculations across the complete stored history. CI verifies container startup and retained data after recreation before publishing an image.

See the [full release notes](docs/releases/v0.1.0.md) for installation, verification and known limitations.
